## Що було зроблено
Реалізовано ігрове поле розміром 20 на 20 клітинок
Додано змійку зі стартовою довжиною 3 клітинки
Керування змійкою працює через клавіші зі стрілками
Додано GUI з Best Score, Current Score, вибором режиму гри та кнопками Play, Exit і Menu
Після програшу поверх поля показується повідомлення Game Over
Найкращий рахунок зберігається у localStorage
Для рендера використовується Pixi legacy з Canvas режимом, щоб гра могла працювати навіть у браузері без доступного WebGL
Стартова швидкість зроблена помірною, а в режимі Speed вона збільшується після кожної зʼїденої їжі

## Режими гри
Classic це класична змійка. Гра закінчується, якщо змійка врізається в край поля або у своє тіло
God mode дозволяє проходити крізь стіни і крізь власне тіло
Walls після кожної зʼїденої їжі додає на поле одну стіну
Portal створює дві клітинки їжі. Якщо змійка зʼїдає одну з них, її голова переноситься в другу клітинку їжі а напрямок руху зберігається
Speed збільшує швидкість руху на 10 відсотків після кожної зʼїденої їжі

## Запуск
У папці проєкту потрібно запустити локальний сервер.

```bash
python -m http.server 5173 --bind 127.0.0.1
```

Після цього гра буде доступна в браузері за адресою:

```text
http://127.0.0.1:5173/
```
